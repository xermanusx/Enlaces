Parrafos

Este es un parrafo p y aunque en el editor demos saltos de línea etc... no se ven reflejados ya que es inmutable. Para dar
saltos de linea, por ejemeplo, se usa la etiqueta br

La etiqueta pre esta enfocada a contener codigo de programación.

Ejemplo

        
            public class HolaMundo {
                public static void main(String[] args) {
                    System.out.println("Hola Mundo");
                }
            }

Como podemos ver el elemento pre, si representa los saltos de línea y utiliza la letra courier
