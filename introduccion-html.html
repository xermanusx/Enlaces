Introducción a HTML

HTML (HyperText Markup Language) es el lenguaje de marcado estándar para crear páginas web. Se utiliza para estructurar contenido en la web mediante el uso de etiquetas.
El lenguaje HTML fue creado por el científico británico Tim Berners-Lee en 1989 mientras trabajaba en el CERN y es la base de todas las páginas web modernas.

Algunas de las etiquetas más comunes en HTML incluyen:

  • <h1> a <h6>: Encabezados de diferentes niveles.
  • <p>: Párrafos de texto.
  • <a>: Enlaces a otras páginas o recursos.
  • <img>: Imágenes.
  • <div>: Contenedores genéricos para agrupar contenido.

HTML es fundamental para el desarrollo web y se combina con CSS y JavaScript para crear sitios web interactivos y visualmente atractivos.
