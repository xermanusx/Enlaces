El atributo style sirve para dar formato a traves del lenguaje css. Background-color sirve
para llenar toda la pagina o superficie de un color y color para dar color a las palabras.
Con font-size se cambia el tamaño de la letra y con font family el estilo de la letra.

Hay varias maneras de dar color. Esta el style="color: red"(Simplemente le decimos el color que queremos)
El background-colorsirve para llenar toda la pagina de un color. Seria style="background-color: yellowgreen"
Y luego hay varias maneras de indicar el color que queremos.
sytle="color: rgb(255,255,255)"(formato RGB) o style="color#11ff33"(que seria un color hexadecimal).
Tambien hay otros formatos como el HSL(Hue, Saturation, Lightness) o el CYMK( C:0, M:0, Y:0, K:0 ).
